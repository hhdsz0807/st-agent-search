# 🔎 Agent 搜索 (Agent Search) — SillyTavern 扩展

一句话:**给它一个关键词,它去百科/搜索源找资料,读完整页正文,让模型整理成「角色模型 / 设定资料」,
写进你指定的世界书**(带激活关键词与绿灯),之后酒馆自己就会按需注入。

引擎来自原「狐搜」插件,现改名重做成独立插件;**旧狐搜的设置会自动接管**,不用重配。

---

## 1. 安装

```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/hhdsz0807/st-agent-search.git agent-search
```

或在酒馆里「安装扩展程序」填上面的仓库地址(那样文件夹名会是 `st-agent-search`,同样能用)。
装完 **刷新页面**。

安装后:

- **设置面板**:扩展 → 🔎 Agent 搜索
- **悬浮入口**:页面右下角一个圆形 🔎 按钮 —— **点一下展开搜索面板**(可拖动,长按复位)
- **斜杠命令**:`/agentsearch 白井黑子`、`/agentlib`(打开资料库)

## 2. 它到底怎么工作的

```
关键词
 ├─ 找网址：自定义搜索源(前 N 条) / 维基百科 / 萌娘百科
 ├─ 读正文：阅读器抓整页(默认不限字数)
 ├─ 整理：模型读「网址 + 正文」→ 输出角色档案
 │        身份 / 外貌 / 性格 / 能力 / 背景 / 人际关系 / 语言风格 / 扮演要点 / 资料来源
 └─ 落库：写进你绑定的世界书(一条词条 = 一个对象,带激活关键词 + 蓝灯/绿灯)
```

整理出来的内容**不会**包含模型的思考过程(会自动剥离 `<thinking>` 之类的块)。

## 3. 搜索源

| 源 | 说明 |
| --- | --- |
| **维基百科(中文)** | 默认开。`list=search` 找条目 → 阅读器读整页 |
| **萌娘百科** | 默认开。走 `opensearch`(萌娘的 `list=search` 已被官方禁用) |
| **自定义搜索源** | 可选。SearXNG 等任何返回 JSON 的搜索接口;它给的**前 N 条网址**会优先交给模型 |
| ~~百度百科~~ | 已移除:403 反爬,正文读不到 |

候选网址会过一遍**过滤与排序**:百度/脸书/推特/B站视频/搜索结果页等直接丢掉,百科类站点优先,同一个站点最多留一条。

## 4. 结果写进世界书(不是浏览器本地)

- 面板 → 结果去向 → **绑定世界书**:选一本现有的,或填名字点「➕ 新建并绑定」
- 每个对象 = 一条**真正的世界书条目**:
  - `comment` = 词条名(列表上看到的那行)
  - `key` = **激活关键词**(默认就是词条名)
  - **🔵 蓝灯** = 常驻注入(不看关键词) / **🟢 绿灯** = 按关键词触发 / **⚪ 关灯** = 禁用
- 资料库窗口是**词条列表**:点词条名展开详情,可改词条名/关键词/正文,可切换灯
- 同一个对象重复搜索 **只更新词条**,不会堆叠
- 记得在角色卡/聊天里**绑定这本世界书**,否则酒馆不会扫它

## 5. 慢/失败怎么办

| 现象 | 原因与处理 |
| --- | --- |
| `finish_reason=length`、**正文 0 字符**、思考几千字 | 推理模型把**输出额度**花在思维链上,和输入无关。→ 分析模型里 **max_tokens 填 32768**、**reasoning_effort 选 `none`**(或 low)。插件也会自动翻倍重试并记住新上限 |
| 提示「中转站没有按请求的 max_tokens 走」 | 上限涨了但思考长度没变 → 该中转站固定了输出上限。→ 换个**非推理模型**做整理,或设 `reasoning_effort` |
| 整理模型失败 | 插件**不会白搜**:会把抓到的原文按站点摘录存进资料库,并在正文里标注「未整理 + 原因」 |
| 搜索很慢 | 面板里限制「最多交给 AI 的网址数」(默认 3)、关掉自定义来源只留维基+萌娘 |
| 想省 token | 单页正文上限填数字(默认 0 = 不限) |

自检(🩺)会打印:搜索源开关、当前生效地址、本次实际请求、任务明细、世界书连接状态、`max_tokens` 与 `reasoning_effort`。

## 6. 目录

```
agent-search/
├─ manifest.json                  # 扩展清单
├─ index.js                       # 主逻辑:面板/悬浮入口/流程编排/世界书写入
├─ agent-core.js                  # 纯逻辑:设置、提示词、URL 筛选、世界书词条、思考剥离(可 node 直测)
├─ settings.html                  # 设置面板模板
├─ style.css                      # 样式
├─ agent-search.default-config.json
├─ EXTRACTED-CONFIG.md            # 引擎来源与提取说明
├─ test-agent-core.mjs            # 87 项单元测试
└─ smoke/run-smoke.mjs            # 90 项冒烟(桩酒馆 + 桩百科 + 桩阅读器)
```

## 7. 开发者

```powershell
cd agent-search
node test-agent-core.mjs     # 纯逻辑
node smoke/run-smoke.mjs     # 端到端(不依赖网络/容器)
```

浏览器控制台调试入口:`window.agentSearch`

```js
window.agentSearch.settings()
await window.agentSearch.search('白井黑子')
window.agentSearch.lastResult()
window.agentSearch.openLibrary()
window.agentSearch.selfCheck()
```
